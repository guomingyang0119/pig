# 安装报价使用指南

安装模块已接入现有 Java + Vue 报价系统，风管、设备和复合报价均可使用。项目名称、地区价格和匹配规则参考 Python，最终计税、取整与导出规则由 Java 执行，运行不依赖 Python。

## 1. 首次启用

进入 **报价管理 → 指标管理 → 安装指标**，点击 **从已核对源表建立草稿**。核对地区、项目名称、销售单价和来源，依次 **保存草稿 → 校验指标 → 发布指标**。

读取基准数据只打开草稿，不会自动发布。已发布版本只读；以后改价先点击 **创建新版本**。停用或过期的最新版本不会回退使用旧价格。风管、设备和安装指标分别管理。

来源为 Python 已核对的《科庆-通风劳务安装报价总汇.xlsx   111(1)(1)(1).xlsx》，共 52 个项目：贵州／四川／云南／广西共用 21 项，陕西 31 项。页面保留原表名称、来源单元格及适用说明。这里是**未税安装销售价**，不会再除利润率或加材料利润。

## 2. 报价员操作

1. 新建或打开报价，填写客户清单和材料条件。
2. 在 **安装报价** 勾选 **本单包含安装**，填写安装省区；切换安装状态后重新选择整单付款方式。
3. 明确是否包含风管安装辅材，填写施工标高和交叉施工条件。
4. 点击每行的 **安装条件**，核对指标项目。项目明确时可按规则自动匹配；有歧义时明确选择原表项目，或填写人工确认的未税安装单价。
5. 独立包裹、现场另列安装等，点 **添加独立安装项目**，填写名称、项目、数量和单位。它们不增加材料供货行。
6. 不含安装的某一项勾选 **本项不含安装** 并填原因。清单整体不计价行会按原规则处理。
7. 点击 **保存并试算**，查看逐项安装数量、单价、未税金额、辅材和待确认原因。全部确认后才能生成正式报价。

弹窗 **确认条件** 只应用到当前草稿，仍需保存；**取消** 不改变原值。正式报价锁定后只能查看安装条件，修改请创建报价修订版。

## 3. 容易混淆的规则

| 情况 | 填写方式 |
|---|---|
| 半成品风管 | 按地区及安装项目匹配销售单价；安装数量使用工程量总面积，不乘材料净面积系数 |
| 成品风管 | 必须人工确认每㎡安装单价，不能直接套半成品价；产品行明确的状态优先 |
| 贵州／四川／云南／广西风管辅材 | 选中包含辅材后按指标计费，基准 8 元/㎡ |
| 陕西风管辅材 | 共板 10、角铁 12、复合 20 元/㎡；按项目或明确选择的辅材类型匹配 |
| 陕西两类功率分档风机 | 小于 1.5kW 为 300；1.5～17.5kW（含端点）为 600；大于 17.5kW 为 800 元/台 |
| 双速风机 | 使用实际选型功率；多档不能自动定价，需人工确认分档功率或安装单价 |
| “个”与“套”等单位不同 | 不自动换算；明确填写安装数量和与所选项目一致的单位 |
| 防雨、远控、多叶、电动等有歧义名称 | 必须选定适用项目或人工单价，不自动选择较近项目 |
| 上述省区以外 | 人工确认安装单价；若需要风管辅材，同时确认辅材单价 |
| 高空或交叉施工 | 四省区超过 5 米、陕西超过 4 米，或勾选交叉施工，必须填写现场附加费；确实无附加费填 0 |

现场附加费填写**整单未税总额**，只加一次；金额大于 0 时必须填写附加原因，原因会进入报价备注。单价为 0 有效；安装数量需大于 0。以上价格随已发布指标版本调整。

## 4. 金额怎么算

```text
本行未税安装费 = 本行安装人工费 + 本行安装辅材费
含税订单的本行安装费 = 向上取整数元（本行未税安装费 × 1.01）
不含税订单的本行安装费 = 向上取整数元（本行未税安装费）
含税现场附加费 = 向上取整数元（录入的未税现场附加费 × 1.01）
不含税现场附加费 = 录入的未税现场附加费
安装费用合计 = 各行安装费之和 + 现场附加费
最终总额 =（材料付款前小计 + 安装费用合计）× 整单付款系数，向上取整数元
```

安装与整单含税口径保持一致。付款系数只在最后乘一次。材料行保持风管一位小数四舍五入、设备整数向上取整；设备运费 8,000 元门槛按付款前、加运费前的材料行金额判断，不包含安装。

正式报价按产品行展示安装费用。每行安装税费和取整只属于本行，不在产品之间分摊。现场附加费作为整单独立项目列示，金额进入安装费用合计，备注显示报价人员填写的附加原因。

例如：含税订单中，0.11㎡共板风管安装单价 30 元/㎡、辅材 8 元/㎡，本行未税安装费为 4.18 元，乘 1.01 后向上取整为 5 元；未税现场附加费 0.03 元单独乘 1.01 后向上取整为 1 元，安装费用合计为 6 元。

## 5. 导出和历史报价

正式报价分为两套模板：

- **不含安装**：使用单层材料模板，只显示材料单价、材料金额和报价合计，不出现安装费用相关列或汇总。
- **包含安装**：使用带安装模板，每个产品行显示材料单价、材料金额、本行安装费用和本行报价；本行报价等于材料金额加本行安装费用。汇总区分别显示材料费用合计、安装费用合计和最终报价合计。

可编辑校对版与正式报价采用相同的行结构。材料已经算出但安装条件仍待确认时，系统保留材料单价和材料金额，只把该行标黄；报价人员在 Excel 的“安装费用”列填写该产品所需的安装费用总额，回导时系统重新计算本行报价和整单三个合计。对客文件不含内部成本、计算公式或来源文件路径。

旧版草稿的计算结果需重新试算。原“整单手填安装费”不会当成每㎡单价或再加一次；页面会显示旧金额供核对，请转填对应安装项目。已定稿报价和已导出文件继续保留原历史结果，通过报价记录下载。

本次无数据库结构或服务配置调整；本机入口仍为 [报价系统](http://127.0.0.1:8888/)。
