## 规则依据

参照原《报价系统》任务及当前 Python duct-v14 实现、测试、README；原任务中的早期记录有过期规则，以当前代码和用户最新确认内容为准。源代码哈希见 python-source-hashes.json。初始化基价是整理后的价格数据，不含原 SQLite、用户、客户或历史报价。

业务重点保留：

- 使用 BigDecimal 运算。材料最终单价按 HALF_UP 保留一位，再乘工程量并将行金额保留一位，按行汇总；没有旧口径的除以 0.75 或角钢乘 0.92。
- 已确认板材与厚度、三种法兰、半成品/成品、直管/异形/不区分、窄管与 1.5mm 特例、净面积系数。
- 共板打孔、按面积或实际数量的配件；行内角钢米数、整单 30#/40# 米数及冲突检查；圆法兰有数量/无数量的两种口径。
- 付款方案必选。系数作用于供货材料和运费，安装费独立处理。圆法兰每米不含税 10、含税 12，不将含税 12 再乘 1.1。
- 指标草稿/校验/发布/新版本/停用/恢复，最新版本失效后不退回旧版本。正式导出前复核当前模板开关与生效指标。
- 客户清单列映射、纵向合并备注、缓存公式警告、原始行保留、不计价原因、权限、并发版本校验、审计。
- 已定稿报价不可修改；导出文件存入数据库快照，并保存模板版本和 SHA-256。历史文件不随规则或模板变化。

正式文件保留已确认模板的对客内容；内部板材吨价、指标公式、计算过程不导入客户文件。
