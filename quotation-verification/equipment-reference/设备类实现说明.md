# 设备供货报价与选型

本次接入设备供货报价、风机选型、设备指标管理和风管设备复合清单。设备安装费不参与本次计算。现有风管公式及金额精度继续独立执行。

## 使用入口

1. 启动更新后的程序。在“指标管理 → 设备指标”点击“从已核对源表建立草稿”。该操作只在页面加载数据，保存后才建立指标草稿。
2. 领导核对毛利、材料吨价、机构、运费、电机等指标后，点击“校验并发布”。已有版本的价格调整使用“新建修订版”，不会改写旧报价记录。
3. 在报价工作台选择“新建设备报价”或“新建复合报价”。导入 Excel 时也可以选择报价类型，核对工作表、产品起始行、名称、规格、数量和单位列。历史单价、金额不用于本次报价。
4. 明确税口径、付款方式及运费。规格中的明确尺寸和参数会自动识别，补填参数优先。按行显示缺项、候选及成本计算依据。点击“保存并试算”。
5. 草稿保留待确认行及其原因。全部必需条件满足后，按系统原有正式模板确认设置导出正式报价，客户文件只包含实际供货规格与售价，不输出成本和内部公式。

设备指标种子尚未自动写入或发布到正式数据库；本次没有重启正式服务，也没有修改桌面源表。

## 计算口径

- 普通设备：不含税成本 ÷ (1−25%) → 付款系数 → 含税时乘 1.1 → 运费 → 最终单价向上取整数元。行金额＝向上取整(最终单价×数量)。各成本分项不提前舍入。
- 运费门槛是**每行未加运费、未取整的供货金额**。低于8000元时填写每台/每个运费，直接加单价；明确填0有效，空白待确认。达到8000元时使用贵州1.03、四川/广西/云南1.05、陕西1.06、海南1.1。其他地区含运费报价不自动计价。
- 远控60元加在机构成本上，再统一除以0.75。例如板式排烟口远控基础机构39元，远控后机构成本99元，不重复加两次60元。
- 阀体宽>1250或高>1000使用拆分计算分支。额外拼接收费独立判断：宽>2000或高>1000，防火/电动阀40元、手动调节阀20元；两边同时超限须填确认拼接成本。止回阀无拼接附加费。
- 连接杆使用本行实际叶片数量。组合送风口/多叶排烟口/板式排烟口按阀体成本+一个面板成本。`350×（1800+250）`中阀体高1800，250为面板标记。
- 圆形阀门、风口及箱体类按对应方形尺寸计算后乘1.5，最后统一取整。圆形尺寸采用直径×直径。风机不因外壳圆形再次加价。
- 风口默认洞口尺寸；散流器默认加70mm，明确喉部尺寸时加130mm。面积成本乘附件倍率后再与保底成本比较。不能把保底成本再乘一次倍率。
- 消声器320×250×1500按截面320×250、长度1500计算；接管箱用静压箱公式。默认单层，明确双层用双层成本。
- 消声弯头“人工面积/方量×200”为固定含税供货价，不加毛利、不重复乘税，仍应用付款和运费；不含税报价按税系数反算。按㎡计价时200就是每㎡单价，面积不重复乘两次。
- 防爆按普通风机不含税成本分档：≤1000为1.4，≤2000为1.6，更高为2；先调整成本，再算毛利。
- 201/304不锈钢阀体及风机的金属成本按对应板厚吨价替换，人工、机构等不变。若源公式只有综合面积成本、没有材料用量分解，系统要求提供核实后的综合面积成本，不用整机成本乘吨价比例冒充材料替换。

上述可调成本和系数保存在发布的设备指标版本中。止回阀拼接费固定为0。

## 风机选型和成本

`产品基价.xlsx/风机如何选型`为主选型依据，另含获准补充的96条SWF记录；算法遵循Word中的主路径和备用路径。

- 主路径优先型号、功率、机号，再用风量风压收敛。`HTF-I`对应`HTF(A)`，`SWF-I`对应`SWF`。功率不得低于要求。主路径仍存在多个合格工况时，报价人员在候选中确认。
- 没有型号和功率时，按风量、风压取有完整成本的最小合格规格。其他系列或原型号无价/性能不满足时，按已确认授权重新选型，保留原要求和替代依据。
- 查本体公式和电机成本必须匹配实际型号、机号、功率及极数。缺成本时先尝试符合性能要求的替代，不能借用邻近电机价格。
- 双速保留功率组合及组号；HTF/SWF普通参数中的高低功率档不能冒充双速。清单给出高低档两组风量/风压时，需要有对应配对数据，不能只核对高速值。
- HTFC-20、750rpm、16536m³/h、18447Pa异常点被隔离。
- “4kW，按11kW单价”的明确备注会按11kW实际配置选型，并在客户报价规格中显示实际型号与功率。

自带阀门的风机整套配置、缺尺寸、风口类型不清、未记录的电机组合等仍标记待确认。这些是具体清单或参数记录需要补齐，不能以默认值强行生成价格。

## 复合清单

同一报价按行分流：类别为“风管”的行调用现有风管引擎，其余行调用设备引擎，保留原清单顺序。风管保持自身一位小数规则，设备向上取整到元，再汇总金额。税口径和付款方案整单统一；风管运费及设备运费分别按各自规则计算。

当复合清单只有一列数量，明确的单位帮助分配：风管㎡数量作为工程量，设备台/个数量作为设备数量；不从旧金额或旧单价反推数量。缺单位/不明确时保留待确认。

## 文件与验证

- `quotation/equipment.py`：分类、参数提取、设备成本、供货售价、复合分流。
- `quotation/equipment_fans.py`：选型、成本完整性校验、替代与候选。
- `quotation/equipment_catalog.py`：指标结构、默认已确认口径及发布校验。
- `quotation/equipment_sources.py` / `import_equipment_catalog.py`：只读解析源表，生成JSON种子，不写数据库。
- `quotation/equipment_export.py`：设备/复合草稿、正式报价公共规格与备注。
- `assets/equipment_catalog_20260924.json`：743条工况、38条本体公式、130条电机价格、12条不锈钢吨价、37条外购基础成本，包含来源单元格及文件SHA256。
- `tests/test_equipment.py`：边界、计价顺序、选型、复合报价、发布与导出回归。
- `tests/ui_equipment_smoke.mjs`：隔离数据库的设备指标发布、页面试算、导出和复合编辑流程。
- `audit_equipment_quotes.py`：只读核对真实清单，输出每行结果与待确认原因。采用明确标注的现金、不含税、不含运费测试条件，**不作为客户报价**。
