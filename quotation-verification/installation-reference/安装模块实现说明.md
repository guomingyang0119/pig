# 安装报价与整单付款

安装模块接入风管、设备及复合报价，依据2026-09-24用户确认的业务规则实现。安装费用均为未税销售价，不再加利润。供货分项保留原有材料税口径及金额精度，付款系数统一改在整单末尾应用。

## 使用

1. 启动更新后的程序，进入“指标管理 → 安装指标 → 从已确认安装表建立草稿”。核对后点击“校验并发布”。草稿和未生效版本不会参与报价；已发布价格修改需创建修订版。
2. 新建或打开风管、设备、复合报价，在“安装报价条件”勾选“本单包含安装”，选择安装地区，并重新选择对应付款方式。
3. 点击清单行，在右侧“本行安装”核对项目、工程量和单位。条件完整且能唯一匹配时自动取价；否则选择安装项目或填写人工未税安装单价。
4. 明确为成品风管时，必须填写每㎡未税安装单价，再乘安装工程量。没有明确成品的安装按半成品处理。单位不同的清单不会自动换算，需明确安装工程量。
5. 按需勾选“包含安装辅材”。高空或交叉施工等现场附加费填写未税总金额，不再次乘工程量；需要现场确认但没有附加费时明确填0。
6. 包裹、软接等额外工序可用“添加附加安装项目”录入。单个清单行不需要安装时，可以选择“本项不计安装”并说明原因。
7. 保存并试算，核对付款前材料小计、含税安装小计和最终报价，再导出草稿或正式报价。

## 计算顺序

```
安装未税金额 = Σ(安装工程量 × 未税安装销售单价)
             + 已选择的未税安装辅材 + 人工确认的未税现场附加费
含税安装小计 = 向上取整数元(安装未税金额 × 1.01)
整单最终报价 = 向上取整数元((付款前材料供货金额 + 含税安装小计) × 整单付款系数)
```

- 风管按㎡、设备按台/个/套等对应工程量计算；安装不使用材料开板/净面积系数。
- 安装单价及各行未税金额不提前向上取整；安装汇总后统一乘1.01并取整，设备安装不沿用设备供货的单价取整规则。
- 四地（贵州、四川、云南、广西）风管安装辅材8元/㎡；陕西共板10、角铁12、复合20元/㎡，仅勾选后计算。包裹及设备已包含的小辅材不自动加风管辅材包。
- 陕西风机档位为小于1.5kW 300元/台、1.5至17.5kW 600元/台、大于17.5kW 800元/台。双速功率不擅自取高档或低档，由报价员确认计费功率或手填单价。
- 设备运费8000元门槛按未乘付款系数、未加运费、未取整的本行供货金额判断，保留供货税口径；安装金额不参与门槛判断。
- 风管及其法兰、角码卡扣、运费均先形成付款前金额。复合报价不会在两个子组分别应用付款或安装税费后再相加；只在最终整单应用一次。
- 风管和设备已发布指标对同一付款方式配置的系数不一致时，复合报价要求核对，不自行选择其中一个。

## 价格依据与人工处理

安装种子保留新版源文件两张表的52个项目行、地区、单位、来源单元格和原表歧义说明；两条陕西设备项目共用原表功率分档。源文件SHA-256为`7376c8f28f0850e238220ee13e0a4303e33783ee3813622ee5e0615f1c69ea34`。50个固定数值单价及2行功率档位已经与源文件逐项核对。

“防雨小于1.5m”等模糊条件不转成猜测规则；项目缺失、区域未覆盖或不能唯一匹配时，支持人工选择项目/填价，并在报价快照中记录价格来源。未知区域没有默认安装价格。单位不一致、未确认功率、成品缺人工单价、必要现场费用未确认等情况阻止正式报价，草稿保留待确认原因。

## 导出与历史报价

- 三类报价均按是否包含安装选择既有“单层材料”或“带安装”正式模板。
- 安装明细、所选辅材、现场费用、安装含税及取整差额分开列示；单价和金额可核对相乘关系。
- 付款前明细保留对应单价，整单付款调整及取整差额另列，避免把系数重复乘进材料或安装单价。导出明细合计与最终对客报价一致。
- 客户导出不显示内部成本、毛利或源表路径；保留此前确认的“含角码卡扣”“含角钢法兰”等适用备注。
- 已导出的文件及历史结果不重写。风管引擎更新为`duct-v16`、设备`equipment-v2`、复合`mixed-v2`，安装规则版本`installation-v1`；旧试算会提示重新保存并试算。旧正式报价通过修订版使用新规则。
- 旧字段`installation_amount`是整单金额，不会当作每㎡单价使用，也不会与新明细重复相加；编辑旧安装报价时会提示重新核对明细。

## 代码位置与验证

- `quotation/installation_catalog.py`：已核对安装价表种子及发布校验。
- `quotation/installation.py`：项目匹配、人工报价、辅材、现场费用、安装汇总和整单付款。
- `quotation/duct.py`、`quotation/equipment.py`：付款前供货计算及复合分组。
- `quotation/web.py`：安装指标版本、安装条件和明细的保存、历史试算版本检查。
- `static/installation_v1.js`：安装指标管理、报价条件、行安装和附加工序。
- `quotation/excel_io.py`、`quotation/equipment_export.py`：草稿及正式导出。
- `tests/test_installation.py`：价格、边界、计算顺序、混合汇总、接口及导出回归。
- `tests/ui_installation_smoke.mjs`：临时数据库中的指标发布、录入、计算、导出、刷新保留及安装开关流程。

验证使用临时数据库和隔离服务；本次代码实施未改动桌面原Excel、未发布正式库指标、未重启正式服务。应用现有指标发布入口仍由领导核对后发布。
